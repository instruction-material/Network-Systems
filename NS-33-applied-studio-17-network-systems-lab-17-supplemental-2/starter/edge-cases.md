1. The route contains .1 but excludes .2. Explain how routeGetServerRouter4 and routeGet4 can differ although both destination strings begin with 198.18.32.
2. An IPv6 query returns an A answer while IPv4 HTTP fails. Separate transport, record and subsequent destination.
3. A /32 host route can reach .2 while omitting other addresses in the supplied /30 server link. Distinguish observed reachability from the task's complete-link route requirement.
4. A route or DNS prerequisite fails before a negative control. State which denial or policy claim is unsupported.
5. Compare the changed-prefix/name/public-port run with the default using each run's own token.
6. Retain a live interruption separately from normal completion and explain actual cleanup and host restoration.
