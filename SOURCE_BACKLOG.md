# Source Backlog Ledger

This ledger records top-level source folders that are present in the repository but are not active catalog starter or solution targets. A folder listed here is intentionally not an unresolved audit failure.

Promotion rule: move a folder out of this ledger only after the course text names where it belongs, whether it is starter or solution material, and how the student or tutor verifies it.

Every learner project folder is linked from the catalog. The validation directories below are support tools.

## Validation Support

- `test/` holds native acceptance tooling for introductory, addressing/naming, isolated router/NAT, owned HTTP capture and isolated UFW policy, IPv6 and application-protocol projects.
- `.github/workflows/` runs that tooling in disposable Linux CI.

These are support directories, not unassigned course projects. The 30 remaining
generic Python pairs are active targets requiring content correction, not
accepted work merely because their files exist.
