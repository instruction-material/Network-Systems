# Listening services map notebook

## Scope and prediction

Record issuing machine, account, time, namespace and the owned examples.
Predict transport, bind address, port, state and visible PID for each example.

## Raw observations

Keep exact commands, raw output, stderr and statuses for filtered and broader
views. Record TCP LISTEN and UDP UNCONN separately, including permission gaps.

## Service classification

For each relevant row record transport, address, port, owner, proposed purpose,
classification (expected, internal-only or review-needed) and supporting facts.
Keep a port-number guess separate from an established application identity.

## Changed case and review

Compare the stopped owned examples with the live observations. Confirm cleanup
or required restoration. Diagram the additional authorized path test and state
what remains unmeasured by this passive local inventory.
