# Starter role

The starter has two deliberate configuration faults. Preserve the first failure, diagnose the first failed boundary, correct the route alone, then correct the proxy upstream.

Read the shared README.md before running `sudo python3 main.py --output ./first-observation` in an owned Linux lab. All role files and the shared guide belong in the export. Use a new output directory per attempt. Both families, actual DNS/HTTP results, listener/policy evidence, the bounded capture and cleanup are required; passing code does not complete the notebook.
