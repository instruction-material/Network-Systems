These are supplied reasoning cases, not additional host measurements.

## Case A: the prompt and the worker disagree

hostname and directory. Which context is actually supported? Name the next
read-only issuing-context observations. The owned fixture does not establish
that an SSH session reached a particular remote host.

## Case B: the selected command is correct, but the data path fails

Explain why PATH correction alone does not change relative-path interpretation.

## Case C: a familiar interpreter name resolves differently
Two owned tool directories contain the same command name. Explain what the
resolved path, actual worker tag, interpreter, PID and cwd establish together.
A namespace string or numeric UID alone is not a globally unique host identity.
